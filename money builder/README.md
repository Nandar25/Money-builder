Money Builder App

 About the Project
This is a simple Money Builder App that I created using React and Vite as part of my learning. The app allows users to add transactions and see their total balance update automatically.

The main aim of this project was to practice the basics of React and understand how components and state work together.

---

Features
- Add a transaction (description and amount)
- View a list of transactions
- Delete a transaction
- Automatically updates the total balance

---

Technologies Used
- React
- Vite
- JavaScript
- HTML & CSS

---

What I Learned
While building this project, I learned:

- How to use **React functional components**
- How to manage data using **useState**
- How to pass data between components using **props**
- How React updates the UI automatically when the state changes
- Basic project structure using Vite
